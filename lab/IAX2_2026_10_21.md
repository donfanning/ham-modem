# IAX2 legs — 2026-10-21

`native/iax` is El-Modem's PyO3 binding over the sans-I/O `iax2` 0.2.2 crate (copied, module renamed
`ham_modem_iax`); `hammodem/audio/iax.py` is an `IaxLeg` with the same leg interface as `SipLeg`
(after El-Modem's `iax_transport.py`): registration, dial-and-keep-up or register-and-answer, 20 ms playout from
the binding's jitter buffer, concealed frames passed on as `ConcealedPcm` (FX.25 erasures).

The crate carries mu-law only, so IAX2 serves the 8 kHz AFSK modes; wideband modes stay on SIP/L16.

Build note: this shell exports `ARCHFLAGS=-arch x86_64`, which makes maturin cross-compile for macOS; build with
`env -u ARCHFLAGS maturin build --release -m native/iax/Cargo.toml -i .venv/bin/python3.12` and pip-install the
wheel. `cargo test` needs `PYO3_PYTHON=.venv/bin/python3.12` (the system Python 3.15 is newer than PyO3 0.27).

Lab: `chan_iax2` loaded in the ham-modem lab PBX only (4569 inside the lab network; nothing on the host). The
`station` friend lives in git-ignored `lab/asterisk/etc/iax_lab_auth.conf` (template: `.example`); stations read
the secret from `HAM_MODEM_IAX_SECRET`.

Results: echo 7399 over IAX2 3/3 (registered, PCMU); room 7300 with 2 IAX2 + 1 SIP stations, 3 x 8 frames, CSMA/CD:
48/48. Rust tests 2/2; `tests/test_iax.py` checks registration/dial traffic against a fake server.
