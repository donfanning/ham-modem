# IL2P (Improved Layer 2 Protocol) — 2026-10-21

`hammodem/il2p.py`, an independent implementation following Direwolf 1.7's `il2p_*.c` (read for the exact
layout -- Debian bookworm's Direwolf 1.6 predates IL2P, so interop was checked against Debian trixie's 1.7):

- No HDLC: raw line levels, MSB first, **no NRZI and no G3RUH scrambler** (Direwolf skips both for IL2P);
  0x55 preamble/postamble, sync 0xF15E48 (accepted with 1 bit error, either polarity).
- Header type 1 (two addresses, 6-bit characters; UI/PID/control/FEC/type/10-bit length down bit columns 6-7)
  or type 0 (whole AX.25 frame as payload, e.g. with digipeaters); 2 RS parity.
- Payload blocks <= 239 (max FEC, 16 parity) or <= 247 bytes (2/4/6/8 parity), larger blocks first.
- IL2P's own scrambler (with Direwolf's 5-bit lag); RS first root **0** and **leading**-zero shortening --
  the opposite of Direwolf's FX.25 on both counts.

Transmit: `--il2p on|max` (AFSK and G3RUH); receive always accepts IL2P on those modems (PAM: not defined).

## Interop with Direwolf 1.7 (20 frames each)

| | result |
|---|---|
| Direwolf `atest` on ours: AFSK 1200 normal / max FEC, G3RUH 9600 max | 20, 20, 20 |
| ours on Direwolf `gen_packets -I 1`, `-I 0`, `-i 1` (inverted), 9600 `-I 1` | 20, 20, 20, 20 |
| 20 ms repeat-last damage per frame, max FEC: ours / Direwolf, on both sources | 20/20 everywhere |
| same damage, normal FEC (4 parity -> 2 bytes; damage ~3 bytes) | ours 1, 0; Direwolf 2, 0 (same behaviour) |

First-try interop, and unambiguous: an IL2P frame cannot fall back to plain HDLC decoding.

## Over VoIP loss: IL2P is the compatibility choice, not the resilience choice

Live, room 7300, 3 stations x 10 short frames, 3% simulated loss, CSMA/CD: IL2P max 45/60 (75%) vs FX.25/32
58/60 (96.7%, same harness earlier). IL2P's sync word tolerates 1 bad bit (FX.25's tag: 8 of 64) and its
header has 2 parity bytes (repairs 1 byte; a lost 20 ms packet at 1200 bd is ~3). For short frames those 18
weakly protected bytes are a quarter of the transmission. Use IL2P to talk to Direwolf 1.7/NinoTNC stations;
use FX.25 (with erasure-aware decoding) for loss resilience. Possible improvement: erasure-aware IL2P decoding
(2 header parity bytes fix 2 erasures).
